FoodBridge – Zero Hunger Project

Project Overview

FoodBridge is a Python prototype designed to support UN Sustainable Development Goal 2 (Zero Hunger) by connecting surplus food donors with NGOs and community kitchens.

Problem Statement

Surplus food may go unused while people in need face difficulties accessing meals. FoodBridge demonstrates a way to coordinate food donations and redistribution.

Features

- Register surplus food donations
- Register NGOs and community kitchens
- Match donations with recipients based on location and serving capacity
- Record completed food handovers
- Display an impact dashboard

Technology Used

- Python 3
- Lists and dictionaries
- Functions and conditional statements
- Rule-based matching

How to Run

1. Open a Python 3 online compiler.
2. Copy the code from "foodbridge.py".
3. Run the program.
4. Select option 7 to load sample data and explore the features.

Future Enhancements

- AI-based surplus food and demand prediction
- Database integration
- Notifications for donors and NGOs
- A web or mobile application
- Verified recipients and food-safety checks

SDG Alignment

This project supports UN SDG 2: Zero Hunger and contributes to reducing avoidable food waste.

Project Status

Functional Python prototype. AI prediction and online deployment are future enhancements.
